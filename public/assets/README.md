# Assets Guide

To restore the visuals in the "HIT ME HARD AND SOFT" app, please upload your screenshots to this folder (`public/assets/`) using the following filenames:

### 1. Global Background
- **Filename**: `global_bg.png`
- **Description**: The dark, underwater atmospheric background.

### 2. The Hero Door
- **Filename**: `door_visual.png`
- **Description**: The white door with the falling figure.

### 3. Featured Vinyl
- **Filename**: `vinyl_featured.png`
- **Description**: The high-contrast vinyl release image.

### 4. Box Office / Live
- **Filename**: `live_box_office.png`
- **Description**: The concert or stage shot.

### 5. Products
- **Filename**: `product_hoodie.png` (Hoodie + CD)
- **Filename**: `product_jersey.png` (Tour Jersey)
- **Filename**: `product_relic.png` (Tour Relic)
- **Filename**: `product_fragrance.png` (Eilish Fragrance)

---
*Note: You can drag and drop these files directly into the File Explorer on the left side of AI Studio.*
